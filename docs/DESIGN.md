# Дизайн-система НарядAI

**Идея:** интерфейс как промышленная маркировка на ГОКе — бирка-допуск на наряде, штампованная табличка оборудования, сигнальная разметка. Всё остальное спокойное и дисциплинированное. Экран исполнителя читается на солнце и нажимается в перчатках.

**Одна запоминающаяся вещь — бирка наряда** (компонент `OrderTag`). Больше ничего «яркого» в интерфейсе нет.

---

## 1. Токены

Токены — CSS-переменные в `frontend/src/index.css`, Tailwind 4 берёт их через `@theme inline`. Светлая и тёмная темы — одни и те же семантические имена, разные значения. Тема по умолчанию — **светлая**; «авто» (тёмная в ночную смену 20:00–08:00) и «тёмная» — в настройках.

### Цвет

Ориентир — приглушённые корпоративные системы (SAP Fiori Horizon, Siemens iX): холодный серо-голубой фон вместо белого, тёмно-синий текст вместо чёрного, глубокий синий в шапке. Не слепит на солнце и не выглядит «траурно».

Базовая палитра (CLAUDE.md, раздел 8):

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `steel` | `#1F2A33` | — | полоса обычного приоритета, тёмные плашки |
| `bar` | `#12305A` | `#0B1014` | шапка приложения и панели |
| `hero` | `#10294A` | `#0D1E33` | фирменная часть экрана входа |
| `km-blue` | `#0B3F8C` | `#6C9BE8` (акцент) | основное действие, полоса под шапкой |
| `signal-yellow` | `#F2C200` | `#F2C200` | «в работе» |
| `signal-red` | `#D7261E` | `#F0473D` | аварийный, просрочка, доработка |
| `ok-green` | `#2E8B3E` | `#4DB560` | «свободен», «принято» |
| `queue-blue` | `#3D74C4` | `#6F9DE3` | «есть очередь» |
| `off-gray` | `#8A9299` | `#7D868D` | «не на смене» |

Семантические токены:

| Токен | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `bg` | `#E4E9EE` | `#10161B` | фон экрана |
| `surface` | `#F6F8FA` | `#18212A` | бирки, поля, листы |
| `plate` | `#DCE2E8` | `#222D37` | утопленные зоны: счётчики, табы, подложка фото |
| `line` | `#C6CFD8` | `#334250` | рамки, разделители |
| `ink` | `#1D2D3E` | `#E4E8E5` | основной текст |
| `ink-2` | `#3D4D5E` | `#B3BDC4` | второстепенный текст |
| `ink-3` | `#56677A` | `#8C979F` | подписи, плейсхолдеры (контраст ≥ 4.5:1 на `bg`) |
| `accent` | `#0B3F8C` | `#6C9BE8` | основная кнопка, ссылки, фокус |
| `on-accent` | `#FFFFFF` | `#0A1A33` | текст на основной кнопке |

Сплошные метки с белым текстом используют плотные оттенки `red-strong #C8231C`, `green-strong #257434`, `queue-strong #3567B3` — у фирменного зелёного `#2E8B3E` с белым текстом контраст 4,4:1, ниже нормы. Фирменные цвета остаются для маркеров, полос и иконок.

**Правило цвета статуса.** Жёлтый = «в работе», синий = «очередь», зелёный = «свободен / готово», серый = «не на смене / отменён», красный = «опасность: авария, просрочка, доработка». Смысл одинаков для людей и нарядов и нигде не меняется. Цвет никогда не единственный носитель смысла — всегда есть текст или форма.

**Приоритет не использует цвета статусов.** Иначе жёлтая полоса «высокого» спорила бы с жёлтым «в работе»:

| Приоритет | Полоса на бирке |
|---|---|
| Аварийный | красно-белая диагональная штриховка (как аварийная лента ограждения) |
| Высокий | сплошная красная |
| Обычный | сплошная стальная |
| Плановый | светлая с пунктирной рамкой |

### Типографика

Roboto — интерфейс; узкое начертание (`font-stretch: 85%`, класс `cond`) — номера нарядов, инвентарные номера, цифры счётчиков и таймеров. Используется **вариативный** Roboto с осями веса и ширины (`@fontsource-variable/roboto`, самохостинг — работает офлайн): в отдельном Plex Sans Condensed нет базовой кириллицы, и русские буквы в номерах собирались бы из чужого шрифта. Подмножества `latin` + `cyrillic` + `cyrillic-ext` (казахские ә ғ қ ң ө ұ ү һ і). Все цифры — `tabular-nums`.

| Роль | Шрифт | Размер / строка | Вес |
|---|---|---|---|
| `display` — счётчики табло | узкий | 44 / 44 | 600 |
| `plate` — номер наряда на бирке | узкий | 28 / 30 | 700 |
| `h1` — заголовок экрана | обычный | 24 / 30 | 600 |
| `h2` — раздел | обычный | 20 / 26 | 600 |
| `body-lg` — текст исполнителя | обычный | 19 / 27 | 400 |
| `body` — основной (минимум на телефоне) | обычный | 17 / 24 | 400 |
| `small` — подписи | обычный | 15 / 20 | 400 |
| `stamp` — надписи на табличке («ИНВ», «ДО») | узкий | 13 / 14 | 600, разрядка 0.06em |

Капсом набраны только штампованные пометки на табличках — как на настоящих бирках. Заголовки — обычным регистром.

### Отступы, размеры

Шаг 4 px: `1=4, 2=8, 3=12, 4=16, 5=20, 6=24, 8=32, 12=48`. Боковые поля телефона — 16 px.

Зоны нажатия: исполнитель — минимум 56 px, главная кнопка — 64 px во всю ширину, внизу экрана в зоне большого пальца. Между опасными кнопками — минимум 16 px. Мастер на десктопе — 40 px.

### Радиусы — по иерархии

| Токен | Значение | Что |
|---|---|---|
| `r-tag` | 3 px | бирка, табличка, бейдж статуса — металл, почти прямой угол |
| `r-control` | 6 px | кнопки, поля, пункты выбора |
| `r-sheet` | 16 px | только верхние углы выезжающего листа |

Пилюль нет нигде.

### Тени — по иерархии

| Уровень | Тень | Что |
|---|---|---|
| 0 — на поверхности | нет, только рамка `line` | бирки в списке, поля |
| 1 — поднято | `0 1px 0 line, 0 2px 4px rgb(31 42 51 / 0.08)` | бирка под пальцем, карточка в канбане при перетаскивании |
| 2 — над экраном | `0 -12px 32px rgb(16 22 27 / 0.28)` | выезжающий лист, тост |
| 3 — перекрывает всё | затемнение 70% | аварийный оверлей |

### Движение

Анимация только как ответ на действие: смена статуса (подсветка бирки жёлтым и затухание за 1,2 с), выезд листа 200 мс, заполнение кнопки удержания 800 мс. `prefers-reduced-motion` — без анимаций, только смена состояния.

## 3. Что здесь выглядело бы как шаблонный SaaS — и что поменяли

Первый набросок был «как у всех»: белые карточки со скруглением 12 px и одинаковой мягкой тенью, цветные пилюли-бейджи, синяя шапка с градиентом, сайдбар с иконками, крупные цифры в отдельных карточках, модальное окно «Вы уверены?», аватары-кружки в канбане, шрифт Inter. Такой интерфейс сделает любая команда за вечер, и ничего не скажет о горно-обогатительном комбинате. Поменяли:

1. **Карточки → бирки.** Плоская поверхность с рамкой, угол 3 px, полоса приоритета с «люверсом», номер как штамп. Тени в списке нет вообще; тень появляется только у того, что над экраном.
2. **Пилюли → штампованные метки.** Прямоугольный бейдж статуса с цветным квадратом-маркером и текстом. Пилюль в системе нет.
3. **Градиентная шапка и сайдбар → стальная плашка.** Тёмная полоса с названием смены, временем и мастером, без градиентов и навигационных иконок. Слева на панели — люди смены, а не меню.
4. **Цифры в карточках → табло.** Счётчики смены — одна утопленная полоса с узкими табличными цифрами, разделёнными тонкими линиями, как табло на диспетчерском пульте.
5. **«Вы уверены?» → удержание.** Опасные действия («Отклонить», «Отменить») подтверждаются удержанием 800 мс с заполнением кнопки — в перчатках это надёжнее, чем попасть в маленькую кнопку диалога.
6. **Аватары → фамилия и инициал.** На производстве людей знают по фамилии; кружки с буквами — шум.
7. **Иллюстрации пустых экранов → подсказка действия.** «Нарядов нет. Новые придут сюда и в Telegram» — одна строка и простая пиктограмма.
8. **Inter → Roboto Variable.** Привычный шрифт Android-телефонов рабочих, полноценная кириллица с казахскими буквами и ось ширины для узких номеров (сначала пробовали IBM Plex, но в его узком начертании на fontsource нет кириллицы).
9. **Анимации появления → только ответ на действие.** Подсветка изменённой бирки, выезд листа, заполнение кнопки удержания. Больше ничего не двигается.
10. **Жёлтая полоса «высокого» приоритета → красная.** Жёлтый занят статусом «в работе»; приоритет говорит формой и красной гаммой, а не чужим цветом.

## 4. Компоненты (`frontend/src/shared/ui`)

| Компонент | Назначение |
|---|---|
| `Button` | основная (64 px, во всю ширину), вторичная, тихая, опасная с удержанием 800 мс |
| `OrderTag` | бирка наряда; варианты: полная, компактная (канбан) |
| `StatusBadge` | статус наряда; `PersonBadge` — статус человека |
| `PersonStatusRow` | строка человека смены со статусом, текущим нарядом или очередью |
| `Counter` / `CounterBoard` | табло счётчиков |
| `BottomSheet` | выезжающий лист (выбор причины, материалов, подтверждения) |
| `Select` | выбор с крупными пунктами в листе, с поиском |
| `Stepper` | количество ± крупными кнопками |
| `PhotoPicker` | до 5 фото, камера или галерея, сжатие на клиенте с сохранением EXIF |
| `PhotoCompare` | слайдер «до / после» |
| `Timeline` | хронология статусов |
| `VerdictCard` | вердикт ИИ с разбором по проверкам |
| `EmptyState` | пустой экран с подсказкой действия |
| `Toast` | короткое сообщение о результате |
| `EmergencyOverlay` | полноэкранный аварийный наряд: звук, вибрация, нельзя закрыть без ответа |
| `TopBar`, `Icon`, `Field`, `Countdown`, `PriorityPicker`, `PinPad`, `Skeleton` | вспомогательные |

Все экраны собираются только из этих компонентов. Каталог всех состояний — страница `/dev/ui`.
