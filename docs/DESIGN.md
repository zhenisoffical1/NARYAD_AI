# Дизайн-система НарядAI

**Идея:** рабочая платформа ТОиР, как настоящие программы для ремонтных служб (MaintainX, UpKeep, SAP Fiori), в фирменных цветах «Костанайских Минералов». Белые поверхности на холодном сером фоне, фирменный синий КМ с переходом в бирюзу у «несущих» элементов, сигнальные цвета статусов. Экран исполнителя читается на солнце и нажимается в перчатках.

**Узнаваемые вещи:** градиентное меню и шапка в цветах КМ, цветные плашки счётчиков смены и бирка наряда (`OrderTag`) с полосой приоритета — у аварийного красно-жёлтая штриховка.

Варианты, из которых выбирали (4 октября 2026): `docs/design-options/v2/` — «Система ТОиР» (выбран), «Мнемосхема фабрики», «Мессенджер».

## 1. Токены

Токены — CSS-переменные в `frontend/src/index.css`, Tailwind 4 берёт их через `@theme inline`. Светлая и тёмная темы — одни и те же семантические имена, разные значения. Тема по умолчанию — **светлая**; «авто» (тёмная в ночную смену 20:00–08:00) и «тёмная» — в настройках.

### Цвет

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `bg` | `#F3F5F8` | `#0E141B` | фон экрана |
| `surface` | `#FFFFFF` | `#161E27` | бирки, карточки, поля, листы |
| `plate` | `#EDF0F4` | `#1E2832` | подложки: табы, колонки канбана, табличка инв. номера |
| `line` | `#DFE3E9` | `#2C3846` | рамки, разделители |
| `ink` | `#172230` | `#E6EBF0` | основной текст |
| `ink-2` | `#44505F` | `#B4BEC8` | второстепенный текст |
| `ink-3` | `#657080` | `#8F9AA6` | подписи (контраст ≥ 4.5:1 на `surface` и `bg`) |
| `accent` (km-blue) | `#0B3F8C` | `#6FA2F0` | основное действие, ссылки, фокус |
| `accent-soft` | `#E6EEFB` | `#1A2A44` | выделенная строка, «проверка ИИ», подсветка изменений |
| `yellow` / `yellow-soft` / `amber` | `#F2C200` / `#FFF1C2` / `#7A5100` | `#F2C200` / `#3A3214` / `#F2C94C` | «в работе»: маркер, фон метки, текст метки |
| `red` / `red-soft` / `red-strong` | `#C8281C` / `#FDEDEB` / `#C8281C` | `#F0574D` / `#3F1D1B` / `#C8281C` | авария, просрочка, доработка |
| `green` / `green-soft` / `green-strong` | `#1E8A45` / `#E3F4E8` / `#17723A` | `#4DB56E` / `#173222` / `#17723A` | «свободен», «принято», «закрыт» |
| `queue` / `queue-soft` | `#2F5FC4` / `#E6EEFC` | `#6F9DE3` / `#1B2A40` | «есть очередь» — светлее фирменного синего |
| `off` | `#8A9299` | `#7D868D` | «не на смене», «отменён» |

**Градиенты — только у несущих элементов**, чтобы они не превращались в украшение каждого блока:

| Токен | Значение (светлая) | Где |
|---|---|---|
| `grad-bar` | `#0B3F8C → #1660C9 → #0E97A6` | шапка экранов, фирменная часть входа, PDF-отчёт |
| `grad-rail` | `#0B3F8C → #0A2F6B → #06204A` | левое меню рабочих мест |
| `grad-primary` | `#1452B0 → #0B3F8C` | основная кнопка |
| `grad-cta` | `#FFD54A → #F2B300` | «Новый наряд» на панели |
| `grad-alarm` | `#FF6A3D → #E5304A → #B5162E` | аварийный оверлей, метка «Аварийный» |
| `grad-page` | `#E9F0FB → bg` за 320 px | лёгкий тон под шапкой у экранов руководителя |

Плашки счётчиков смены — тоже градиенты, цвет несёт смысл: синий — выдано, зелёный — выполнено, красный — просрочено (только если не ноль), оранжевый — оборудование в простое (только если не ноль). Нулевые плашки нейтральные, белые, чтобы цвет кричал только о проблеме.

**Правило цвета статуса.** Жёлтый = «в работе», синий = «очередь», зелёный = «свободен / готово», серый = «не на смене / отменён», красный = «опасность: авария, просрочка, доработка», фирменный синий = «проверка ИИ». Смысл одинаков для людей и нарядов и нигде не меняется. Цвет никогда не единственный носитель смысла — у метки всегда есть текст, у полосы приоритета — подпись для экранного диктора.

**Приоритет не использует цвета статусов:**

| Приоритет | Полоса на бирке | Метка |
|---|---|---|
| Аварийный | красно-жёлтая диагональная штриховка | белый текст на `grad-alarm` |
| Высокий | градиент оранжевый → красный | красный текст на `red-soft` |
| Обычный | серая | — |
| Плановый | пунктир | — |

### Типографика

**IBM Plex Sans** (`@fontsource/ibm-plex-sans`, 400/500/600/700, самохостинг — работает офлайн). Строгий инженерный гротеск IBM, полноценная кириллица с казахскими ә ғ қ ң ө ұ ү һ і (подмножество `cyrillic-ext`, проверено на экранах `*-kk.png`). Номера нарядов, инвентарные номера, цифры табло и таймеров — тем же шрифтом с табличными цифрами (`cond`: `tabular-nums`, трекинг −0.01em); отдельного узкого начертания нет, потому что у Plex Sans Condensed нет кириллицы.

| Роль | Размер / строка | Вес |
|---|---|---|
| `display` — счётчики табло | 44 / 44 | 700 |
| номер наряда на бирке | 24 (компактная 19) | 700 |
| `h1` — заголовок экрана | 24 / 30 | 700 |
| `h2` — раздел | 20 / 26 | 600 |
| `body-lg` — текст исполнителя | 19 / 27 | 400 |
| `body` — основной (минимум на телефоне) | 17 / 24 | 400 |
| `small` — подписи | 15 / 20 | 400 |
| `stamp` — подписи меток и счётчиков | 13 / 16 | 600 |

Капса нет: подписи строчными, как в обычной речи.

### Отступы, размеры

Шаг 4 px: `1=4, 2=8, 3=12, 4=16, 5=20, 6=24, 8=32, 12=48`. Боковые поля телефона — 16 px.

Зоны нажатия: исполнитель — минимум 56 px, главная кнопка — 64 px во всю ширину, внизу экрана в зоне большого пальца. Между опасными кнопками — минимум 16 px. Мастер на десктопе — 40 px.

### Радиусы — по иерархии

| Токен | Значение | Что |
|---|---|---|
| — | 5–6 px | метки статуса, табличка инв. номера |
| `r-control` | 8 px | кнопки, поля |
| `r-tag` | 10 px | бирка наряда, плашка счётчика |
| — | 12 px | блоки (`Panel`), колонки канбана, карточка наряда |
| `r-sheet` | 18 px | верхние углы выезжающего листа |

Круглые только точки статуса, аватары с инициалами, индикатор вкладки и полосы графиков.

### Тени — по иерархии

| Уровень | Тень | Что |
|---|---|---|
| 0 — карточка | `0 1px 2px rgb(23 34 48 / .05)` | бирки, блоки, плашки |
| 1 — поднято | `0 1px 2px …, 0 6px 16px -8px rgb(11 63 140 / .22)` — с синим оттенком | бирка под курсором, выбранная вкладка |
| 2 — над экраном | `0 -12px 32px rgb(16 22 27 / .28)` | выезжающий лист, тост |
| 3 — перекрывает всё | весь экран | аварийный оверлей |

У основной и жёлтой кнопок — цветная тень своего оттенка.

### Движение

Анимация только как ответ на действие: смена статуса (подсветка бирки фирменным голубым и затухание за 1,2 с), выезд листа 200 мс, заполнение кнопки удержания 800 мс. `prefers-reduced-motion` — без анимаций, только смена состояния.

### Бирка наряда (`OrderTag`)

```
 ┌──┬─────────────────────────────────────────────────────────┐
 │▞▞│ №147  [ОБ-007]  [Аварийный]               (● В работе)  │
 │▞▞│ Насос гидравлический Н-7                                │

Внизу — исполнитель с инициалами (у исполнителя на телефоне — участок) и срок с обратным отсчётом; при просрочке разделитель становится красным пунктиром, а срок — «просрочен на 0:45».

## 3. Почему так, а не «как у всех»

Первые четыре темы (4 октября) отличались только цветами на одной раскладке — заказчик назвал их «тусклыми» и «сгенерированными». Второй круг строили от реальных рабочих продуктов, а не от токенов:

1. **Образец — настоящие программы ТОиР.** Меню разделов слева, список и карточка работы рядом, лента событий, метки статуса с точкой — то, что мастер и руководитель видели в MaintainX, UpKeep, 1С:ТОиР. Интерфейс выглядит как инструмент, а не как лендинг.
2. **Градиенты только у несущих элементов.** Меню, шапка, главная кнопка, авария и счётчики. Карточки, поля и таблицы — белые и спокойные, иначе цвет перестаёт что-то значить.
3. **Цвет плашки счётчика = смысл.** Красная «Просрочено» появляется только когда просрочка есть; ноль — белая плашка.
4. **«Вы уверены?» → удержание.** Опасные действия («Отклонить», «Отменить») подтверждаются удержанием 800 мс с заполнением кнопки — в перчатках это надёжнее, чем попасть в маленькую кнопку диалога.
5. **Инициалы у исполнителя.** В канбане и списках цветной кружок с инициалами находится глазом быстрее фамилии; цвет постоянный для человека.
6. **Пустые экраны → подсказка действия.** «Нарядов нет. Новые придут сюда и в Telegram» — одна строка и простая пиктограмма.
7. **IBM Plex Sans.** Инженерный шрифт с полной казахской кириллицей; отличается от Inter/Roboto, которые стоят по умолчанию у шаблонов.
8. **Анимации — только ответ на действие.** Подсветка изменённой бирки, выезд листа, заполнение кнопки удержания.
9. **Высокий приоритет — красный, не жёлтый.** Жёлтый занят статусом «в работе».

## 4. Компоненты (`frontend/src/shared/ui`)

| Компонент | Назначение |
|---|---|
| `Button` | основная (градиент КМ, 64 px во всю ширину у исполнителя), `cta` (жёлтая), вторичная, тихая, опасная с удержанием 800 мс |
| `OrderTag` | бирка наряда; варианты: полная, компактная (канбан); `Initials` — кружок с инициалами |
| `StatusBadge` | статус наряда; `PersonBadge` — статус человека |
| `PersonStatusRow` | строка человека смены со статусом, текущим нарядом или очередью |
| `Counter` / `CounterBoard` | цветные плашки табло (`tone`: blue, green, red, amber) |
| `BottomSheet` | выезжающий лист (выбор причины, материалов, подтверждения) |
| `Select` | выбор с крупными пунктами в листе, с поиском |
| `Stepper` | количество ± крупными кнопками |
| `PhotoPicker` | до 5 фото, камера или галерея, сжатие на клиенте с сохранением EXIF |
| `PhotoCompare` | слайдер «до / после» |
| `Timeline` | хронология статусов |
| `VerdictCard` | вердикт ИИ с разбором по проверкам |
| `EmptyState` | пустой экран с подсказкой действия |
| `Toast` | короткое сообщение о результате |
| `EmergencyOverlay` | полноэкранный аварийный наряд: звук, вибрация, нельзя закрыть без ответа |
| `TopBar`, `Icon`, `Field`, `Countdown`, `PriorityPicker`, `PinPad`, `Skeleton` | вспомогательные |

Каркас рабочих мест на компьютере — `features/desk/DeskShell` (левое меню) и `DeskHeader` (шапка).

Все экраны собираются только из этих компонентов. Каталог всех состояний — страница `/dev/ui`.
