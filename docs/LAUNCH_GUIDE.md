## Часть 0. Основы, которые понадобятся везде

### 0.1. Как открыть PowerShell в папке проекта

PowerShell — это окно, куда вводят команды текстом.

1. Откройте **Проводник** (жёлтая папка на панели задач или клавиши **Win + E**).
2. Слева нажмите **Рабочий стол**.
3. Двойной щелчок по папке **NaryadAI**.
4. Щёлкните **один раз** по адресной строке вверху окна (где написан путь к папке) — путь выделится синим.
5. Напечатайте `powershell` и нажмите **Enter**.

**Должно получиться:** открылось синее или чёрное окно, в последней строке что-то вроде `PS C:\Users\...\NaryadAI>`.

### 0.2. Как вставить команду

1. В этой инструкции команды стоят в серых рамках. Выделите текст команды мышью и нажмите **Ctrl + C**.
2. Щёлкните в окно PowerShell **правой кнопкой мыши** — текст вставится сам.
3. Нажмите **Enter**.
4. Дождитесь, пока снова появится строка `PS ...>` — значит, команда закончилась.

### 0.3. Как открыть файл `.env` в Блокноте

`.env` — файл с настройками и ключами в папке NaryadAI.

1. В Проводнике в папке **NaryadAI** найдите файл **.env** (если не видно — вверху **Просмотр → Показать → Скрытые элементы**).
2. Щёлкните по нему **правой кнопкой → Открыть с помощью → Блокнот**.
3. После правки — **Ctrl + S** (сохранить) и закройте Блокнот.

## Шаг 3. Создать Telegram-бота (10 минут)

1. Откройте Telegram на телефоне или компьютере.
2. В поиске вверху наберите **BotFather**. Выберите того, у кого **синяя галочка** рядом с именем.
3. Нажмите **Start** (или «Запустить») внизу.
4. Отправьте сообщение:
   ```
   /newbot
   ```
5. BotFather спросит имя. Отправьте:
   ```
   НарядAI — Костанайские Минералы
   ```
6. BotFather спросит логин (username). Он должен быть латиницей и кончаться на `bot`. Отправьте, например:
   ```
   naryadai_km_bot
   ```
   Если ответит, что занято (`Sorry, this username is already taken`) — попробуйте `naryadai_km2026_bot`, `naryad_ai_kostanay_bot` и т.п.
7. BotFather пришлёт длинное сообщение. В нём строка после **«Use this token to access the HTTP API»** — это **токен**, вида `8123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
8. Нажмите на токен — он скопируется. Сохраните его в Блокнот на компьютере (файл `ключи.txt` на рабочем столе, **не в папке проекта**). Рядом запишите логин бота без `@`.

   > ⚠ Токен — это пароль от бота. Не отправляйте его в общие чаты и не выкладывайте в интернет.

**Красивое оформление бота (по желанию, 3 минуты):**

9. Отправьте `/setuserpic` → нажмите на своего бота в появившихся кнопках → отправьте картинку с эмблемой КМ (файл `NaryadAI\frontend\public\brand\km-logo.png`, отправьте как фото).
10. Отправьте `/setdescription` → выберите бота → отправьте текст:
    ```
    Наряды смены: новые наряды с кнопками «Принять» и «В очередь», напоминания о сроках, аварийные вызовы.
    ```

**Должно получиться:** в Блокноте записаны токен и логин бота.

## Шаг 4. Ключ ИИ (Claude) и проверка точности (20 минут)

Без ключа система работает на правилах. С ключом включаются сравнение фото «до/после», проверка работ моделью и текстовые выводы. Для защиты ключ очень желателен.

### 4.1. Регистрация

1. Откройте https://console.anthropic.com
2. Нажмите **Sign up** / **Continue with Google** (проще всего через Google-аккаунт).
3. Подтвердите почту, если попросят (письмо от Anthropic → кнопка в письме).
4. Если спросят название организации — напишите название команды; цель использования — любой подходящий вариант.

### 4.2. Пополнить баланс

1. Слева внизу или в меню нажмите **Settings** (Настройки) → **Billing**.
2. Нажмите **Buy credits** / **Add funds**.
3. Введите сумму **10 $** (хватит с большим запасом) и данные банковской карты → подтвердите.

**Должно получиться:** на странице Billing виден баланс больше нуля.

### 4.3. Создать ключ

1. В меню нажмите **API Keys**.
2. Нажмите **Create Key**.
3. Название: `naryadai` → **Create** / **Add**.
4. Появится ключ, начинается с `sk-ant-`. Нажмите **Copy**. **Он показывается один раз!**
5. Вставьте его в свой `ключи.txt`.

### 4.4. Вписать ключ в проект и проверить точность

1. Откройте `.env` в Блокноте (пункт 0.3).
2. Найдите строку `ANTHROPIC_API_KEY=` и вставьте ключ сразу после знака `=`, **без пробелов и кавычек**:
   ```
   ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxx
   ```
3. **Ctrl + S**, закройте Блокнот.
4. Откройте PowerShell в папке проекта (0.1) и вставьте:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tasks.ps1 ai-eval
   ```
5. Подождите 3–8 минут — пойдут строки с проверкой 30 случаев.

**Должно получиться:** в конце строки с точностью (например «Точность: 29 из 30») и временем проверки. **Сделайте скриншот и пришлите мне** — я впишу результат в README и презентацию.

## Шаг 5. Арендовать сервер (15 минут)

Сервер — это компьютер в интернете, который работает круглосуточно, чтобы жюри могло открыть систему в любой момент. Ниже — на примере **Hetzner** (недорогой, надёжный). Нужна банковская карта; около 5–7 € в месяц, через месяц сервер можно удалить.

1. Откройте https://www.hetzner.com/cloud и нажмите **Sign up** / **Register**.
2. Заполните почту и пароль → подтвердите почту по ссылке из письма.
3. Заполните данные (имя, адрес) и добавьте карту. Hetzner может попросить подтверждение личности — следуйте его подсказкам (иногда фото документа). Если это неудобно — подойдёт **DigitalOcean** или казахстанский **PS.kz**: последовательность такая же — «создать сервер», Ubuntu 24.04, 2 ядра и 4 ГБ памяти.
4. Войдите в **Cloud Console** (https://console.hetzner.cloud).
5. Нажмите **+ New project** → название `naryadai` → **Add project** → щёлкните по созданному проекту.
6. Нажмите **Add Server** / **Create Server**.
7. Заполните:
   - **Location** — любое (например Helsinki или Falkenstein);
   - **Image** — **Ubuntu 24.04**;
   - **Type** — **Shared vCPU → x86**, тариф с **2 vCPU и 4 GB RAM** (обычно называется **CX22**);
   - **Networking** — галочка **Public IPv4** включена;
   - **SSH keys** — пропустите (тогда пароль придёт на почту);
   - **Name** — `naryadai`.
8. Внизу нажмите **Create & Buy now**.
9. Через минуту сервер появится в списке. Скопируйте его **IP-адрес** (4 числа через точки, например `95.217.10.20`) в `ключи.txt`.
10. Проверьте почту — придёт письмо с **root password** (паролем). Скопируйте его в `ключи.txt`.

**Должно получиться:** в `ключи.txt` есть IP-адрес сервера и пароль root.

## Шаг 6. Бесплатный адрес сайта (5 минут)

Нужен адрес вида `naryadai.duckdns.org`, чтобы работал защищённый HTTPS (без него телефон не даст камеру и уведомления).

1. Откройте https://www.duckdns.org
2. Вверху справа войдите через **Google** или **GitHub**.
3. В поле **sub domain** введите `naryadai` (если занято — `naryadai-km`, `naryad2026` и т.п.) → нажмите **add domain**.
4. В появившейся строке с вашим доменом в поле **current ip** сотрите то, что там есть, и вставьте **IP сервера** из шага 5 → нажмите **update ip**.
5. Запишите адрес в `ключи.txt`, например `naryadai.duckdns.org`.

**Должно получиться:** в таблице на DuckDNS ваш домен и IP сервера.

Дальше в инструкции этот адрес называется **ВАШ_ДОМЕН**.

## Шаг 7. Подключиться к серверу (5 минут)

1. Откройте PowerShell (можно в любой папке: **Пуск** → напечатайте `PowerShell` → Enter).
2. Вставьте, заменив `IP_СЕРВЕРА` на ваш IP:
   ```powershell
   ssh root@IP_СЕРВЕРА
   ```
3. Если спросит `Are you sure you want to continue connecting (yes/no)?` — напечатайте `yes` и Enter.
4. `password:` — скопируйте пароль из `ключи.txt` и вставьте **правой кнопкой мыши**. **Символы не будут видны — это нормально.** Нажмите Enter.
5. Hetzner сразу попросит сменить пароль:
   - `Current password:` — вставьте старый пароль ещё раз, Enter;
   - `New password:` — придумайте новый надёжный пароль, вставьте, Enter;
   - `Retype new password:` — ещё раз, Enter.
   
   Запишите новый пароль в `ключи.txt`.

**Должно получиться:** строка вида `root@naryadai:~#` — вы «внутри» сервера. Все команды до конца шага 9 вводятся в **это** окно.

> Если окно закрылось — снова сделайте пункты 1–4 этого шага (с новым паролем).

## Шаг 8. Установить нужные программы на сервер (10 минут)

Вставляйте по одной команде, после каждой ждите строку `root@...:~#`.

1. Обновление системы (2–5 минут; если появится розовое окно с вопросом — просто нажмите **Enter**):
   ```bash
   apt update && apt upgrade -y
   ```
2. Docker — программа, которая запускает систему:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
3. Git и make:
   ```bash
   apt install -y git make
   ```
4. Открыть доступ к сайту:
   ```bash
   ufw allow 22 && ufw allow 80 && ufw allow 443 && ufw --force enable
   ```
5. Проверка:
   ```bash
   docker compose version
   ```

**Должно получиться:** строка вида `Docker Compose version v2.xx.x`.

## Шаг 9. Запустить систему на сервере (30 минут, большую часть — ожидание)

### 9.1. Скачать проект

```bash
cd /opt && git clone https://github.com/zhenisoffical1/NARYAD_AI.git naryadai && cd naryadai
```

Если спросит `Username` — репозиторий приватный. Проще сделать его публичным (всё равно нужно для жюри): на GitHub в репозитории **Settings** → в самом низу **Change visibility** → **Make public** → подтвердите. Затем повторите команду.

**Должно получиться:** строка заканчивается на `/opt/naryadai#`.

### 9.2. Создать файл настроек

1. Скопируйте образец:
   ```bash
   cp .env.example .env
   ```
2. Сгенерируйте секрет:
   ```bash
   openssl rand -hex 32
   ```
   Появится длинная строка из букв и цифр. **Выделите её мышью** (в PowerShell выделение = копирование) и вставьте в `ключи.txt` как «JWT секрет».
3. Откройте настройки в редакторе:
   ```bash
   nano .env
   ```
4. Откроется текст. Мышь здесь не работает — двигайтесь **стрелками** на клавиатуре. Нужно поменять 7 строк. Для каждой: встаньте стрелками в конец строки, клавишей **Backspace** сотрите старое значение после `=`, вставьте новое **правой кнопкой мыши**:

   | Строка | Что должно быть после `=` |
   |---|---|
   | `JWT_SECRET=` | секрет из пункта 2 |
   | `DEMO_MODE=` | `true` (уже стоит, не трогайте) |
   | `ANTHROPIC_API_KEY=` | ключ из шага 4 (`sk-ant-...`) |
   | `TELEGRAM_BOT_TOKEN=` | токен бота из шага 3 |
   | `TELEGRAM_BOT_USERNAME=` | логин бота **без @** |
   | `PUBLIC_URL=` | `https://ВАШ_ДОМЕН` (например `https://naryadai.duckdns.org`) |
   | `SITE_ADDRESS=` | `ВАШ_ДОМЕН` **без https://** (например `naryadai.duckdns.org`) |

5. Сохранить: **Ctrl + O**, затем **Enter**. Выйти: **Ctrl + X**.
6. Проверьте, что всё записалось:
   ```bash
   grep -E "SITE_ADDRESS|PUBLIC_URL|TELEGRAM_BOT_USERNAME|DEMO_MODE" .env
   ```
   **Должно получиться:** ваш домен, логин бота и `DEMO_MODE=true`.

### 9.3. Собрать и запустить

```bash
docker compose up -d --build
```

Пойдут сотни строк — это нормально. **Ждите 10–20 минут**, пока не вернётся строка `root@...#`. В конце должны быть строки со словами `Started` / `Healthy`.

### 9.4. Проверить, что всё запущено

```bash
docker compose ps
```

**Должно получиться:** 5 строк (`db`, `backend`, `scheduler`, `bot`, `frontend`), у всех в колонке STATUS — `Up`.

### 9.5. Заполнить тестовыми данными

```bash
make seed
```

**Должно получиться:** через 1–3 минуты строки «Справочники: 25 ед. оборудования…», «История: … нарядов», «Готово».

> ⚠ `make seed` стирает всю базу и создаёт заново. Перед показом жюри так делать не нужно — для сброса демо-смены есть кнопка «Пересоздать смену» на пульте `/demo`.

## Шаг 11. Проверить на Android-телефоне (30 минут)

Нужно 2 телефона (лучше 3): мастер и исполнитель. Браузер — **Google Chrome**.

### 11.1. Вход и установка приложения на телефон исполнителя

1. На компьютере откройте `https://ВАШ_ДОМЕН/demo`.
2. На телефоне откройте **Камеру** и наведите на QR-код **«Слесарь — свободен»**. Нажмите на появившуюся ссылку → откройте в **Chrome**.
3. Телефон войдёт в систему без ПИН.
4. В Chrome нажмите **⋮** (три точки вверху справа) → **Добавить на главный экран** или **Установить приложение** → **Установить**.
5. На рабочем столе телефона появится значок **НарядAI**. Дальше открывайте через него.
6. Когда приложение спросит разрешения — **Разрешить** уведомления, камеру и микрофон.
   - Если случайно нажали «Запретить»: в Chrome откройте сайт → значок слева от адреса → **Разрешения** → включите.
7. Включите звук на телефоне и выключите режим «Не беспокоить».

### 11.2. Подключить Telegram на телефоне исполнителя

1. В приложении внизу нажмите **Профиль**.
2. Нажмите **Подключить Telegram**.
3. Откроется Telegram с вашим ботом → нажмите **Start** / **Запустить**.
4. Вернитесь в приложение — там должно быть «Telegram подключён».

### 11.3. Телефон мастера

То же самое, но QR-код **«Мастер смены»**. Telegram — тоже подключите через профиль (значок человечка вверху справа).

### 11.4. Репетиция сценария защиты

1. Компьютер: войдите `master1` / `2222` — откроется панель смены.
2. Пульт `https://ВАШ_ДОМЕН/demo` → кнопка **Пересоздать смену**.
3. **Телефон мастера:** **Новый наряд** → **Фото** (сфотографируйте любое оборудование) → в поиске оборудования напишите `Н-7` → выберите насос → в приоритете **Аварийный** → в описании напишите или наговорите «Течь масла из-под уплотнения» → вверху списка исполнителей метка ИИ — выберите его → **Выдать**.
4. **Телефон исполнителя:** красный экран со звуком + сообщение в Telegram. Нажмите **Принять в работу** → откроется наряд → **Начать**. На компьютере карточка переедет в колонку «В работе».

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| Сайт не открывается | на DuckDNS проверьте, что указан правильный IP (шаг 6); подождите 5 минут |
| Предупреждение «небезопасное подключение» | в `.env` в `SITE_ADDRESS` домен должен быть **без** `https://`; затем `docker compose up -d`. Порты 80 и 443 должны быть открыты (шаг 8, пункт 4) |
| «502 Bad Gateway» | подождите 2 минуты после запуска; если не прошло — на сервере `docker compose logs backend --tail=50`, скриншот мне |
| Сборка оборвалась со словом `killed` | у сервера меньше 4 ГБ памяти — выберите тариф побольше |
| Бот не пишет | в `/api/health` должно быть `"telegram":"on"`; на телефоне в профиле — «Telegram подключён» |
| Не работает камера или микрофон | сайт открыт не по `https://` или запрещено в разрешениях (шаг 11.1, пункт 6) |
| Нет звука аварийного | беззвучный режим или «Не беспокоить»; коснитесь экрана приложения один раз после открытия — браузер разрешает звук только после касания |
| «Неверный ПИН» и вход заблокирован | после 5 ошибок вход блокируется на несколько минут — подождите |
| Данные «сломались» на репетиции | на сервере `cd /opt/naryadai && make seed` (полный сброс, 2–3 минуты) |
| Не знаю, что произошло | на сервере `cd /opt/naryadai && docker compose ps` → скриншот мне вместе со скриншотом ошибки |
