## 2. Проблемы из ТЗ — чем закрыты

| Проблема | Чем закрыта |
|---|---|
| Наряды теряются, срочные ждут | приоритеты, сортировка по срочности, аварийный — полноэкранно со звуком, эскалация через 3 мин |
| Поиск свободного исполнителя | цветные статусы людей, ИИ-подбор кандидата, ассистент «кто свободен из электриков» |
| Нет подтверждения выполнения | форма закрытия: работы, шифр, материалы, фото «после», ИИ-проверка |
| Простои не считаются | признак «оборудование остановлено», простой по наряду и оборудованию, отчёт по простоям |
| Повторные поломки не замечают | детекторы повторов и роста поломок, история оборудования в карточке наряда |
| Нет объективной оценки | оценка ИИ каждого наряда с правкой мастера, рейтинг исполнителей и бригад |

## Что сделать команде до 8 октября

1. Развернуть на сервере с доменом: `SITE_ADDRESS`, `docker compose up -d`, `make seed`; проверить вход с Android по HTTPS.
2. Создать Telegram-бота у @BotFather, задать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME`.
3. Задать `ANTHROPIC_API_KEY`, прогнать `make ai-eval` с моделью, обновить цифру в README.
4. Собрать APK из PWA (PWABuilder) — по желанию.
5. Презентация (до 10 слайдов) и видео (до 3 минут).
6. Вычитка казахского носителем.
