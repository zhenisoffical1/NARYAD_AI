# Тестовые учётные записи

Регистрации в системе нет намеренно: на предприятии сотрудников заводит администратор (раздел «Справочники» или импорт из 1С / табеля CSV-файлом). Все записи ниже создаёт команда `python -m seed` (в Docker — `docker compose exec backend python -m seed`).

Вход: http://localhost:5173 (без Docker) или http://localhost (в Docker) → логин → ПИН на цифровой клавиатуре.

## Где лежит база

- Без Docker — файл SQLite `backend/naryad.db`. Открыть можно программой DB Browser for SQLite: таблица `employees` — люди, `orders` — наряды, `order_events` — журнал.
- В Docker — PostgreSQL в контейнере `db` (пользователь и пароль `naryad`).
- API с документацией и кнопкой «Try it out»: http://localhost:5173/api/docs (без Docker) или http://localhost/api/docs.

ПИН в базе хранится только в виде хэша — прочитать его оттуда нельзя, поэтому он записан здесь.
