# НарядAI — промпты для Claude Code по этапам

Порядок: этапы с одинаковой датой идут параллельно у разных людей. Каждый работает в своей ветке (`feat/backend`, `feat/worker`, `feat/panel`, `feat/ai`) и вливает в `main` минимум раз в день. За `main` отвечает Человек 1.

Роли:
- **Ч1** — бэкенд и тимлид;
- **Ч2** — приложение исполнителя + мобильный экран мастера;
- **Ч3** — дизайн-система, веб-панель мастера, дашборд руководителя;
- **Ч4** — данные и ИИ.

К каждому промпту Claude Code автоматически подтягивает `CLAUDE.md`. Если сессия долгая и он «забывает» правила, начни новую сессию или напиши: «Перечитай CLAUDE.md и docs/PROGRESS.md».

---

## Этап 0. Подготовка (3 октября, вечер, все вместе, 30 минут)

Руками:
1. Создать репозиторий на GitHub, положить в корень `CLAUDE.md`, в `docs/` — `case1.pdf` (PDF кейса).
2. Создать Telegram-бота через @BotFather, сохранить токен.
3. Получить `ANTHROPIC_API_KEY` (для приложения; работать будет и без него в mock-режиме).
4. Арендовать VPS (любой с Docker) и домен или поддомен — нужен HTTPS для камеры в PWA.
5. Ч1 запускает этап 1, остальные ждут, пока каркас попадёт в `main` (примерно 1–2 часа).
