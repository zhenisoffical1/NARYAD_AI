# Бесплатный вариант: всё на своём ноутбуке, без единого платежа

Система работает на вашем ноутбуке в Docker, а бесплатный туннель Cloudflare даёт ей публичную ссылку с HTTPS — её можно открыть с любого телефона и отправить жюри. Карта, сервер и ключи ИИ не нужны.

**Чем платите вместо денег:**

| Ограничение | Что делать |
|---|---|
| Ссылка работает, только пока ноутбук включён, не спит и окно туннеля открыто | на время проверки жюри держите ноутбук включённым от розетки (шаг 3) |
| После перезапуска туннеля ссылка **меняется** | не закрывайте окно туннеля; если всё же сменилась — шаг 6.3 и сообщите организаторам новую ссылку |
| ИИ работает без языковой модели — на правилах (точность 93%) | так и задумано: система полностью рабочая. Не будет только сравнения фото «до/после» моделью (пункт «желательно»); проверка фото по времени съёмки и на повтор (MVP) работает |

Делайте по порядку. После каждого шага — **«Должно получиться»**; если не так, пришлите скриншот.

Основы (как открыть PowerShell в папке проекта, как вставлять команды, как открыть `.env` в Блокноте) — в части 0 файла [LAUNCH_GUIDE.md](LAUNCH_GUIDE.md).

## Шаг 3. Чтобы ноутбук не засыпал

1. **Пуск** → **Параметры** (шестерёнка).
2. **Система** → **Питание и батарея** (или «Питание»).
3. Раскройте **Экран, спящий режим и гибернация** (или «Экран и спящий режим»).
4. Для **«При питании от сети»** поставьте у пунктов «Переводить устройство в спящий режим» значение **Никогда**.
5. Подключите ноутбук к розетке.

Крышку на время работы не закрывайте (или: **Панель управления → Электропитание → Действие при закрытии крышки → «Действие не требуется»** для «От сети»).

**Должно получиться:** при питании от сети — «Никогда».

## Шаг 4. Docker Desktop

У вас он уже установлен.

1. **Пуск** → напечатайте **Docker Desktop** → откройте.
2. Подождите 1–2 минуты, пока внизу слева окна станет зелёным **Engine running** (значок кита в трее перестанет мигать).
3. Если попросит войти в аккаунт — можно нажать **Skip** / **Continue without signing in**.
4. Чтобы запускался сам: в Docker Desktop шестерёнка **Settings** → **General** → галочка **Start Docker Desktop when you sign in to your computer** → **Apply**.

**Должно получиться:** в PowerShell команда
```powershell
docker compose version
```
печатает `Docker Compose version v2...`.

> Если пишет «docker не является внутренней или внешней командой» — закройте PowerShell, откройте заново (после запуска Docker Desktop). Не помогло — перезагрузите компьютер.

## Шаг 6. Запустить систему и получить публичную ссылку

### 6.1. Настройки

1. Откройте `.env` в папке NaryadAI Блокнотом (часть 0.3 основной инструкции).
2. Поменяйте строки (остальное не трогайте):

   | Строка | Значение |
   |---|---|
   | `DATABASE_URL=` | **не трогайте** — в Docker она подменяется сама |
   | `JWT_SECRET=` | любая длинная случайная строка из латинских букв и цифр, 40+ символов (настучите по клавиатуре: `k8f3Jq9x2Lm7Wp4Zr6Tn1Vb5Hc0Ys8Dg3Ue7Fa2`) |
   | `DEMO_MODE=` | `true` |
   | `ANTHROPIC_API_KEY=` | **оставьте пустым** |
   | `TELEGRAM_BOT_TOKEN=` | токен из шага 2 |
   | `TELEGRAM_BOT_USERNAME=` | логин бота без `@` |
   | `SITE_ADDRESS=` | `:80` |
   | `PUBLIC_URL=` | пока оставьте как есть — поменяем в 6.3 |

3. **Ctrl + S**, закройте Блокнот.

### 6.2. Собрать и запустить

1. PowerShell в папке проекта.
2. Вставьте:
   ```powershell
   docker compose up -d --build
   ```
   Первый раз — **15–30 минут** (скачивает и собирает). Ждите строку `PS ...>`.
3. Проверьте:
   ```powershell
   docker compose ps
   ```
   **Должно получиться:** 5 строк (`db`, `backend`, `scheduler`, `bot`, `frontend`), у всех `Up`.
4. Наполните тестовыми данными:
   ```powershell
   docker compose exec backend python -m seed
   ```
   **Должно получиться:** «Справочники… История… Готово».
5. Откройте в браузере http://localhost — экран входа с эмблемой КМ.

### 6.3. Публичная ссылка через Cloudflare (бесплатно, без регистрации)

1. Установите программу туннеля. В PowerShell:
   ```powershell
   winget install --id Cloudflare.cloudflared
   ```
   Если спросит согласие с условиями — напечатайте `Y` и Enter. После установки **закройте и снова откройте PowerShell**.
2. Запустите туннель:
   ```powershell
   cloudflared tunnel --url http://localhost:80
   ```
3. Через 5–10 секунд в рамке появится строка вида:
   ```
   Your quick Tunnel has been created! Visit it at:
   https://слова-через-дефис.trycloudflare.com
   ```
   Скопируйте эту ссылку (выделите мышью) в `ключи.txt`. Дальше она называется **ВАША_ССЫЛКА**.

   > ⚠ **Это окно не закрывайте** — пока оно открыто, ссылка работает. Сверните его.

4. Сообщите системе её адрес (для ссылок в Telegram и QR-кодов входа): откройте `.env` Блокнотом → строка
   ```
   PUBLIC_URL=https://слова-через-дефис.trycloudflare.com
   ```
   → **Ctrl + S**.
5. В **новом** окне PowerShell в папке проекта примените:
   ```powershell
   docker compose up -d --force-recreate backend scheduler bot
   ```

**Должно получиться:** ВАША_ССЫЛКА открывается в браузере на телефоне (через мобильный интернет, не Wi-Fi — так проверяется, что доступ есть извне), с замком в адресной строке.

**Если ссылка сменилась** (перезагрузка, закрыли окно туннеля): повторите пункты 2–5 этого шага и отправьте организаторам новую ссылку.

## Шаг 10. APK — бесплатно (по желанию)

## Каждый раз после перезагрузки ноутбука

1. Запустите **Docker Desktop**, дождитесь **Engine running**. Система поднимется сама (данные сохраняются).
2. PowerShell в папке проекта:
   ```powershell
   cloudflared tunnel --url http://localhost:80
   ```
3. Ссылка будет **новой** → шаг 6.3, пункты 3–5, и сообщите новую ссылку.

## Перед показом жюри на Demo Day

На месте ноутбук и телефоны подключите к одной сети (лучше раздать интернет с телефона), запустите туннель, откройте `ВАША_ССЫЛКА/demo` → **Пересоздать смену**. Видео — скачано на ноутбук как запасной вариант.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| `docker compose up` пишет, что порт 80 занят | закройте программы, которые могут его держать (Skype, IIS, другие серверы), или перезагрузите компьютер |
| Сборка очень долгая или оборвалась | проверьте интернет и запустите ту же команду ещё раз — продолжит с места остановки |
| ВАША_ССЫЛКА не открывается | окно туннеля закрыто или ноутбук уснул — шаг «Каждый раз после перезагрузки» |
| Открывается, но «502» / ошибка | Docker Desktop не запущен или система ещё стартует — подождите 1–2 минуты, `docker compose ps` |
| Бот не отвечает | `ВАША_ССЫЛКА/api/health` → `"telegram":"on"`? Если `off` — проверьте токен в `.env`, затем `docker compose up -d --force-recreate bot` |
| В Telegram кнопки ведут на старую ссылку | `PUBLIC_URL` в `.env` не обновлён — шаг 6.3, пункты 4–5 |
| Данные испорчены на репетиции | `docker compose exec backend python -m seed` (полный сброс) |

Любую ошибку — скриншотом мне вместе с выводом `docker compose ps`.
