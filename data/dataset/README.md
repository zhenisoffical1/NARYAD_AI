# Тестовый набор данных НарядAI

Выгрузка того же набора, что создаёт `python -m seed` (генератор детерминирован, seed=42): справочники в объёме ТЗ и история нарядов за 3 месяца с журналом, оценками ИИ, списаниями и простоями. Обновить файлы:

```bash
cd backend && python -m seed.export
```

CSV в UTF-8 с BOM, разделитель «;» — открываются в Excel двойным щелчком. Время — UTC. Хэши ПИН и идентификаторы Telegram не выгружаются.

| Файл | Что внутри | Строк |
|---|---|---|
| `sections.csv` | участки | 4 |
| `equipment.csv` | оборудование: инв. номер, участок, тип, критичность A/B/C, код QR | 25 |
| `brigades.csv` | бригады | 3 |
| `employees.csv` | сотрудники: роль, специальность, разряд, бригада, смена | 19 |
| `fault_codes.csv` | шифры неисправностей М, Э, Г, П, С | 20 |
| `materials.csv` | материалы и запчасти с единицами | 40 |
| `time_norms.csv`, `time_norm_materials.csv` | нормативы времени и расхода материалов по шифрам | 20 / 48 |
| `orders.csv` | наряды с временем каждого перехода, простоем, работами | 560+ |
| `order_events.csv` | журнал: кто, что, когда, из какого статуса в какой, причина | 3600+ |
| `ai_assessments.csv` | вердикты ИИ-проверки, баллы, правки мастера | 560+ |
| `material_writeoffs.csv` | списания материалов по нарядам | 1200+ |
| `photos.csv` | фото (в архивной истории их нет — как при переносе бумажного журнала) | 0 |

## Заложенные закономерности

Аналитика находит все пять — это проверяет тест `backend/tests/test_analytics.py`:

1. Конвейер К-3 ломается в 3 раза чаще среднего, большинство поломок за последние 30 дней — шифр М-02 (подшипник).
2. У одного исполнителя около 30% нарядов возвращаются на доработку или с повторной поломкой в течение 7 дней.
3. Дробилка КМД-1750 ломается в течение 5 дней после ППР бригады №2.
4. На участке обогащения электрические отказы (Э-*) ночью в 2,5 раза чаще, чем днём.
5. Один исполнитель списывает смазочные материалы в 2–3 раза выше нормы.
